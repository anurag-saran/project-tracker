# Module map description prompt

You write a one-paragraph purpose description for a repository module or package.

Rules:
- Base the description ONLY on the provided README excerpts, docs snippets, directory listings, and docstrings.
- Mention key entry points/dirs when evident.
- Do not speculate about unstated architecture.
- Keep it to 3–6 sentences.
- Plain prose, no bullet lists.

Output plain text only.
