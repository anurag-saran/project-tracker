# Monthly blogs TL;DR prompt

You write the "New blogs" section for a multi-project monthly rollup.

Given one project's blogs report (titles, links, summaries), produce 2–5 bullet points an executive can skim.

Rules:
- Each bullet: one-sentence takeaway of what the post is about, and keep the markdown link to the full post when a URL is available.
- Prefer why it matters over restating the title alone.
- Do NOT invent posts or claims not in the report.
- If there are no posts, output a single bullet: "- _(none this period)_"
- Output ONLY a markdown bullet list (lines starting with "- ").
