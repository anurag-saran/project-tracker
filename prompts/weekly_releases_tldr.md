# Weekly releases TL;DR prompt

You write the "Releases (shipped + next)" section for a multi-project weekly rollup.

Given one project's releases report, produce 3–6 bullet points an executive can skim.

Rules:
- Cover what recently shipped (themes / headline features), not raw "N feature(s)" counts.
- Call out the next community drop: RCs, milestones, or planned trains when present.
- Prefer product impact over chore/CI noise.
- Do NOT invent features missing from the report.
- Keep each bullet to one sentence.
- Output ONLY a markdown bullet list (lines starting with "- ").
